# 🚀 AI-Powered Project Management SaaS - Backend Core

This is the enterprise-grade backend core engine for the AI-Powered Project Management platform, built using **NestJS**, **Prisma ORM**, and **PostgreSQL**.

## 🛠️ Tech Stack

*   **Framework:** NestJS (TypeScript)
*   **Database ORM:** Prisma
*   **Database:** PostgreSQL
*   **Validation:** Class-validator & Class-transformer

## 📂 Directory Structure (Core)

```text
backend-core/
├── prisma/               # Database blueprint & migration files
└── src/                  # NestJS application source code
    ├── prisma/           # Global Prisma database bridge module
    ├── project/          # Project management business logic
    ├── app.module.ts     # Main application root module
    └── main.ts           # Server entry point configuration
